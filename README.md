# aims1425-lab

Building public tooling around self-hosted AI agents, Hermes Agent deployment, secure automation, and repeatable QA workflows.

## Focus

- Production-oriented Hermes Agent deployment
- Public-safe agent skills and workflows
- Browser QA automation with Playwright
- Security hygiene for tokens, bots, webhooks, and self-hosted services
- OSS maintainer workflows: CI, releases, documentation, issue triage, and hardening

## Featured repositories

- [hermes-deploy](https://github.com/aims1425-lab/hermes-deploy) — production-ready Hermes Agent deployment template with Docker, security hardening, Telegram integration, CI, releases, and maintainer docs.
- [hermes-agent-public-skills](https://github.com/aims1425-lab/hermes-agent-public-skills) — public-safe Hermes Agent skill pack for OSS readiness, QA, deployment operations, and secret hygiene.

## Maintainer direction

I keep public repositories focused on reusable infrastructure, documentation, validation, and security. Private customer data, credentials, and commercial project details do not belong in public repos.
